# Scientific Inference Lab

[Website](https://scientific-inference-lab.github.io/)

Scientific Inference Lab at Pusan National University develops machine learning methods for scientific discovery and informed decisions.

Research spans AI for Science, Industrial AI & Decision-Making, Evidence-Centered AI, and Continuous-Time Modeling.
